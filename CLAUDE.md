## Process

1. Ensure you correctly understand the goal
2. Make a tentative plan of execution, and maintain a to-do list, presented to the user
3. Interview the user for any ambiguity, and explain the plan
4. Recieve go/no go
5. Implement the plan
6. Let the user test the results, waiting for okay to proceed
7. Interview the user for feedback
8. Document in this document (CLAUDE.md) and in NOTES.md
